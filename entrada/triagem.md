# Registro de triagem

Uma linha por item que entrou em `entrada/novos/`. O original fica em `entrada/triados/`, sem alteração.

**Tipos:**

- **primária:** documento produzido pelo próprio ator (governo, tribunal, empresa);
- **pesquisa:** resposta de outra conversa ou relatório de terceiros;
- **nota:** texto do usuário;
- **terceiros:** material com direitos, que fica só como link.

**Status das afirmações:** *pista* (não conferida), *conferida* (fonte original lida, com data) ou *descartada* (com o motivo).
